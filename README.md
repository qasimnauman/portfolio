# Qasim Nauman - Portfolio (Next.js)

This is the portfolio website for **Muhammad Qasim Nauman**, a DevOps Engineer specializing in AWS, Azure, Kubernetes, Docker, and Terraform.

## 🚀 Tech Stack

- **Framework**: Next.js 16.1.1 (App Router)
- **React**: 19.2.3
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React, React Icons, Font Awesome
- **Fonts**: Poppins (Custom)

## ✨ Features

- ✅ Server-side rendering (SSR) for better SEO
- ✅ Optimized images with Next.js Image component
- ✅ File-based routing (no React Router needed)
- ✅ Responsive design
- ✅ Fast page loads with automatic code splitting
- ✅ Custom Poppins font integration

## 📦 Getting Started

First, install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Then run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

```

├── src/
│   ├── app/                    # Next.js App Router
│   │   ├── layout.js          # Root layout with Navbar/Footer

│   │   ├── about/             # About page

│   │   ├── gallery/           # Gallery page

│   ├── components/            # React components
│   ├── data/                  # JSON data files
│   └── hooks/                 # Custom React hooks
└── public/                    # Static assets
```
